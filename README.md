Instrucciones
El objetivo es evidenciar la comprensión del flujo de trabajo básico con Git: crear un proyecto, conectarlo con GitHub, realizar cambios y registrar versiones mediante commits.

Instrucciones clase en video > CLASE REMOTA 25376-20260806_000127UTC-Meeting Recording.mp4 

    Cree un repositorio local llamado: BPDS
    Cree un repositorio público en GitHub con el mismo nombre y conecte su repositorio local al repositorio remoto


Y dentro del proyecto cree la siguiente estructura:

BPDS/
│
└── CRUD/
    ├── index.html
    ├── styles.css
    └── app.js

Para el primer commit, únicamente debe existir la estructura anterior. Es decir, se debe evidenciar:

    El proyecto creado BPDS
    La carpeta CRUD.
    Y los tres archivos: index.html, styles.css, app.js


Para el segundo commit, realice las siguientes modificaciones:

Cree un archivo README.md y llénelo, en la raíz del proyecto.
Agregue contenido al archivo README.md.
Escriba cualquier contenido en index.html.
Escriba cualquier contenido en styles.css.
Escriba cualquier contenido en app.js.

Finalmente, registre estos cambios mediante un segundo commit y súbalos al repositorio remoto en GitHub. Git registra automáticamente la fecha y la hora en la que se realiza cada commit. Por esta razón, los commits deben corresponder a la sesión de clase de esta semana y reflejar el trabajo realizado durante la práctica.

Entrega: únicamente deberán enviar el enlace público de su repositorio de GitHub.
